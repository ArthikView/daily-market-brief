# The Daily Market Brief

A responsive, independent static publication by **Chandan Pathak [Economist]**.

## Included
- Responsive homepage and author profile
- Editorial coverage sections
- Searchable archive populated from `issues/index.json`
- Reusable daily article template
- Free hosting through GitHub Pages

## Publish with GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then click **Save**.
4. Wait for deployment. The expected address is https://arthikview.github.io/daily-market-brief/

## Add a daily edition
1. Copy `issues/issue-template.html` to a dated file such as `issues/2026-11-23.html`.
2. Replace all bracketed placeholders with verified reporting and analysis.
3. Add the edition to `issues/index.json`.
4. Commit the changes.

## Editorial standards
- Verify prices, index levels, dates and data at the original source.
- Prefer RBI, MOSPI, NSO, NSE, BSE, SEBI, government ministries and central banks.
- Separate **Reported facts** from **Analysis**.
- Link material claims to sources and retain publication dates.
- Do not invent forecasts or present scenarios as facts.
- Keep the disclaimer visible.
